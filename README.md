# 열달의 식탁


<br/>

## 1. 서비스 개요

### 열달의 식탁은 임산부를 위한 AI 맞춤형 식단 추천 및 영양성분 관리 앱 서비스입니다.

<p style="text-align: left;">
    1. AI를 활용한 개인 맞춤형 식단을 매일 제공합니다.
    2. 음식 사진을 찍어 오늘 먹은 음식의 영양성분을 분석하고 저장하여 나만의 영양성분 캘린더를 관리할 수 있습니다.
    3. 임신 중 조심해야 할 음식, 성분 등이 궁금하면 챗봇 기능을 활용하여 해결할 수 있습니다.
</p>
